# 文件上传目录

这个目录用于存储用户上传的文件。

## 目录结构

```
uploads/
├── avatars/          # 用户头像文件
└── README.md         # 说明文件
```

## 配置说明

- 最大文件大小：10MB
- 头像文件大小限制：2MB
- 支持的图片格式：jpg, jpeg, png, gif, bmp, webp
- 访问路径：http://localhost:8080/uploads/

## 注意事项

1. 该目录会在应用启动时自动创建
2. 上传的文件会自动生成唯一文件名，格式：时间戳_UUID.扩展名
3. 请确保应用有足够的磁盘空间和写入权限
